What’s inside

Built for the space between appointments. Calm, modern, and private.

Butterfly BLS

Left–right iridescent butterfly or rainbow orb. Visual, stereo tones, or both. Slow to custom speed, timed sets, fullscreen, and a pause between sets.

Stabilize first

Safe place, container, and nurturing, protective, or wise resource figures. Phase 2 before any target work.

Grounding

5-4-3-2-1, box breathing, and a slow body scan. One tap from Calm now if a set feels like too much.

Guided session

Seven steps: check-in, target and SUDS, cognition and VOC, sets, install, reevaluation, closure.

Journal & progress

Private notes with optional mood and tags. SUDS trends and set counts stay on the device. JSON backup when you want one.

Learn the map

Eight phases, how bilateral stimulation is used, CPTSD pacing notes, and a simple green–amber–red safety map.

How a visit feels

Between sessions

  1. Open Meridian EMDR from the home screen. It works offline after the first load.
  2. If the day is loud, start with a safe place or grounding. No target required.
  3. When you are steady, run a short butterfly set. Stop if the room slips away.
  4. Note what shifted. Bring the pattern to your clinician. The app does not replace them.

What stays private

No account. No cloud sync. Sessions, journal, safe places, and settings live in local storage under meridian-emdr-v1. Export a JSON backup, or wipe the device copy in Settings.
